# User stories и критерии приёмки

1. **Как участник**, я хочу зарегистрироваться по email и паролю, чтобы получить доступ к рабочему пространству. **Приёмка:** валидный email и пароль ≥8 символов создают пользователя; повторный email отклоняется; пароль не хранится открытым.
2. **Как пользователь**, я хочу войти и выйти, чтобы безопасно пользоваться системой. **Приёмка:** вход выдаёт access/refresh; неверные данные дают 401; выход отзывает refresh-токен.
3. **Как тимлид**, я хочу создать проект, чтобы организовать работу команды. **Приёмка:** название обязательно; создатель добавляется участником с ролью lead.
4. **Как участник**, я хочу видеть только проекты, в которых состою, чтобы не получать доступ к чужим данным. **Приёмка:** список фильтруется на сервере; прямой запрос к чужому проекту отклоняется.
5. **Как тимлид**, я хочу создавать задачи с приоритетом и сроком, чтобы распределять работу. **Приёмка:** название обязательно; статус и приоритет проверяются сервером.
6. **Как участник**, я хочу перемещать задачи по канбан-доске, чтобы отражать ход работы. **Приёмка:** изменение статуса сохраняется в БД и появляется в истории.
7. **Как участник**, я хочу искать и фильтровать задачи, чтобы быстро находить нужные. **Приёмка:** поиск по названию/описанию и фильтры выполняются сервером; параметры пагинации ограничены.
8. **Как тимлид**, я хочу создавать спринты, чтобы планировать работу на период. **Приёмка:** название обязательно; дата окончания не раньше даты начала.
9. **Как участник**, я хочу комментировать задачи, чтобы обсуждать детали выполнения. **Приёмка:** комментарий не может быть пустым; доступ проверяется через проект.
10. **Как пользователь**, я хочу видеть профиль и менять пароль, чтобы поддерживать актуальные данные и безопасность. **Приёмка:** изменение пароля требует текущий пароль; новый пароль ≥8 символов.
11. **Как администратор**, я хочу менять роли пользователей, чтобы управлять доступом. **Приёмка:** endpoint доступен только admin; неизвестная роль отклоняется.
12. **Как администратор**, я хочу блокировать аккаунты, чтобы прекращать доступ нарушителей. **Приёмка:** блокировка сохраняется; заблокированный пользователь не может войти.
13. **Как преподаватель**, я хочу видеть статистику проекта, чтобы оценивать прогресс. **Приёмка:** dashboard возвращает общее число, завершённые и просроченные задачи, распределение по статусам.
14. **Как участник**, я хочу прикреплять файлы к задаче, чтобы делиться материалами. **Приёмка:** разрешены только указанные типы и размер до лимита; путь хранится в задаче.
15. **Как пользователь**, я хочу переключать тёмную тему, чтобы выбрать удобное оформление. **Приёмка:** тема переключается без перезагрузки и сохраняется в браузере.
