# Спецификация макетов Figma

Создать отдельный Figma-файл `TaskFlow MVP`, затем вставить ссылку в README перед сдачей. Этот документ не заменяет реальные макеты.

1. **Вход:** логотип, email, пароль, сообщение об ошибке, кнопка входа.
2. **Канбан-доска:** боковая навигация, заголовок проекта, карточки статистики, поиск/фильтр, пять колонок, карточка задачи.
3. **Создание задачи:** название, описание, исполнитель, приоритет, срок, прикрепление файла.
4. **Аналитика:** карточки метрик, график статусов, просроченные задачи.
5. **Администрирование:** таблица пользователей, роль, статус, действия блокировки.

Сделать адаптивные варианты для 360 px, 768 px, 1280 px и 1920 px; определить цвета, типографику, отступы, состояния loading/empty/error и UI-kit.
